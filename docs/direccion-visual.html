PetCommunity · Dirección visual

Azul profundo, blanco y un acento cálido.

Propuesta de base visual para aprobar antes de programar. Es el mismo comportamiento que tendrá la app: sigue al dispositivo, y se puede forzar claro u oscuro a mano.

Esto es una maqueta HTML para decidir. La app real usará estos mismos tokens como propiedades CSS personalizadas en Angular Native.

Paleta

Azul oscuro moderado como color dominante, acento ámbar para acciones principales y rojo reservado a mascotas perdidas, para que una alerta nunca se confunda con un error cualquiera.

Contraste medido

Texto normal necesita al menos 4,5:1 (WCAG AA). Calculado con la fórmula de luminancia relativa, no a ojo.
